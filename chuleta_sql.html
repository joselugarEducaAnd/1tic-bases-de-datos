Estructura básica de una consulta

SELECT col1, col2, ...    -- columnas
FROM   tabla              -- tabla
WHERE  condición          -- filtro
ORDER BY campo ASC|DESC;  -- orden

SELECT * devuelve todas las columnas. Cada sentencia termina en ;. Cadenas: 'comillas simples'. Los identificadores no se entrecomillan en SQLite.

Operadores en WHERE

Operador Significado Ejemplo
= igual a genero = 'Novela'
<> distinto de genero <> 'Novela'
< > <= >= mayor/menor anio < 1950
AND y anio>2000 AND genero='Novela'
OR o genero='Novela' OR genero='Fantasía'
NOT niega NOT (anio < 2000)

Ordenar

ORDER BY anio ASC;            -- ascendente (por defecto)
ORDER BY anio DESC;           -- descendente
ORDER BY genero, anio DESC;   -- 1.º género, luego año desc

LIKE — patrones de texto

Comodín Significa
% cualquier secuencia (incluida vacía)
_ exactamente un carácter 
WHERE titulo LIKE '%viento%'   -- contiene "viento"
WHERE autor  LIKE 'García%'    -- empieza por "García"
WHERE nombre LIKE '_a%'        -- 2.ª letra es "a"

Tildes: LIKE 'fantasia' no encuentra 'Fantasía'. Copia la tilde.

BETWEEN — rangos (inclusivos)

WHERE anio BETWEEN 1950 AND 2000
WHERE fecha BETWEEN '2025-10-01' AND '2025-10-31'

BETWEEN x AND y ≡ >= x AND <= y. Las fechas son TEXT en formato ISO 'aaaa-mm-dd' con comillas simples.

IS NULL — campos vacíos

WHERE campo IS NULL        -- vacío
WHERE campo IS NOT NULL    -- con valor

(En el editor gráfico de Base se escribía IS EMPTY. En SQL puro siempre IS NULL.)

JOIN — combinar tablas

SELECT P.fecha_prestamo, L.titulo
FROM   Prestamos AS P
JOIN   Libros    AS L
       ON P.id_libro = L.id_libro;
  • JOIN ≡ INNER JOIN. Solo filas con pareja en ambas tablas.
  • Une por la columna común: PK padre = FK hija.
  • Alias con AS: Prestamos AS P → P.columna.
  • Encadena más JOIN para 3+ tablas.

LEFT JOIN — incluir lo huérfano

SELECT R.nombre, P.fecha_prestamo
FROM   Lectores  AS R
LEFT JOIN Prestamos AS P
       ON R.id_lector = P.id_lector;

Trae todas las filas de la izquierda. Las que no tienen pareja a la derecha aparecen con NULL.

Filtro típico para “solo huérfanos”: WHERE columna_de_la_derecha IS NULL.

INSERT — añadir filas

INSERT INTO Libros
  (titulo, autor, genero, anio, ejemplares)
VALUES
  ('Pedro Páramo', 'Juan Rulfo', 'Novela', 1955, 2);
  • Columnas y valores: mismo orden y número.
  • En SQLite, INTEGER PRIMARY KEY se autoasigna (puedes omitirlo).
  • En SQLime, tras un INSERT verás 0 rows. No es error. Verifica con un SELECT.

UPDATE — modificar filas

UPDATE Libros
SET    ejemplares = 5
WHERE  id_libro = 1;

Sin WHERE se modifican TODAS las filas. Escribe siempre el WHERE.

DELETE — borrar filas

DELETE FROM Prestamos
WHERE  id_prestamo = 7;

Sin WHERE se borran TODAS las filas. Mismo aviso.

SQL en tu .odb (LibreOffice Base)

Base usa HSQLDB, no SQLite. Dos cambios obligatorios al pegar SQL en Herramientas → SQL…:

1. Comillas dobles en identificadores (tabla y columnas):

INSERT INTO "Libros" ("titulo", "autor")
VALUES ('X', 'Y');

Sin comillas: Column not found: TITULO.

2. id_X manual: HSQLDB no autoincrementa.

INSERT INTO "Libros"
  ("id_libro","titulo","autor",
   "genero","anio","ejemplares")
VALUES (13,'…','…','…',1985,3);

Sin id: Attempt to insert null into id_libro.

Esquema de biblioteca.db

Libros    (id_libro PK, titulo, autor,
           genero, anio, ejemplares)
Lectores  (id_lector PK, nombre, apellidos,
           curso, email)
Prestamos (id_prestamo PK,
           id_libro FK, id_lector FK,
           fecha_prestamo, fecha_devolucion)

Errores típicos

Error Arreglo
no such table: X Carga biblioteca.db con open file.
no such column: X Pulsa tables y comprueba el nombre.
ambiguous column: id_X Prefija con alias: P.id_libro.
WHERE con texto sin resultados 'comillas simples' para texto.
LIKE 'fantasia' no encuentra Fantasía Copia la tilde: '%Fantasía%'.
BETWEEN con fechas vacío 'aaaa-mm-dd' con comillas simples.
IS EMPTY da error En SQL puro: IS NULL.
WHERE x = NULL no devuelve nada IS NULL / IS NOT NULL.
INSERT/UPDATE/DELETE da 0 rows Normal en SQLime. Verifica con SELECT.
Column not found: TITULO (Base) Comillas dobles: "titulo", "Libros".
Attempt to insert null into id_X (Base) Da el id manualmente en el INSERT.
